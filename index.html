PERSONALIZÁ TU CALENDARIO

Configuración

Elegí cómo se generan los días y adaptá los turnos a tu régimen.

1. Tipo de planificación

2. Datos para calcular la rotación

Indicá un franco que tengas confirmado. Desde esa fecha la aplicación calcula los próximos ciclos.

Turno nocturno: si el último turno termina al día siguiente (por ejemplo, 23:00–06:00), se marca la salida a las 06:00 y el franco queda ubicado después de esa salida. El día de salida no se cuenta como franco.

2. Configurar turnos fijos

Asigná un turno, franco o descanso a cada día. La configuración se repite todas las semanas.

3. Mis turnos y horarios

Podés cambiar los horarios, los nombres, los colores y el orden de rotación.

4. Colores del calendario

Elegí un color para diferenciar los francos, los descansos y las salidas.

5. Respaldo de datos

Exportá un archivo JSON para guardar tu configuración o transferirla a otro dispositivo. La importación reemplaza los datos actuales.

La aplicación funciona sin conexión después de la primera carga. Los datos no se envían a un servidor.
